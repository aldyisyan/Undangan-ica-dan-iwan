Tempatkan foto/ilustrasi Anda di folder ini agar otomatis tampil di website.

Nama file yang dipakai oleh website:
- our-1.jpg  -> foto pertama galeri
- our-2.jpg  -> foto kedua galeri
- our-3.jpg  -> foto ketiga galeri
- our-4.jpg  -> foto keempat galeri

Boleh format JPG / JPEG / PNG, tetapi agar langsung cocok tanpa ubah kode,
simpan dengan nama berikut:
- our-1.jpg
- our-2.jpg
- our-3.jpg
- our-4.jpg

Cara kerja (urutan prioritas):
1. Jika ada foto yang diupload lewat Admin Panel -> tab "Media & Foto",
   foto tersebut yang dipakai dan folder ini diabaikan.
2. Jika tidak ada upload di Admin Panel, website memindai folder ini.
   File yang tidak ditemukan otomatis dilewati.
3. Jika keduanya kosong, website memakai ilustrasi bawaan.

Catatan penting:
- Folder ini hanya terbaca bila SELURUH folder hasil build (dist/) ikut
  diunggah ke hosting. Bila hanya file index.html saja yang diunggah,
  pakai Admin Panel -> tab "Media & Foto" agar foto tersimpan di cloud.
- Jika file belum ada, website otomatis memakai ilustrasi bawaan (tidak ada
  kotak kosong).
- Rasio portrait atau square sama-sama aman.
